Key Features

01

🔐 Privacy by Default

Phone and email stay hidden until both users explicitly consent to share. Enforced at the API level.

02

✅ Claims Review

Finders manually approve or reject claims. No auto-approval — items only go to someone who can prove ownership.

03

💬 Private Chat

Secure one-on-one chat per item. Contact details revealed only after mutual agreement.

04

🔔 Push Notifications

Real-time browser notifications for messages, claims, and decisions — even when the site is closed.

05

🗂️ Multi-Tab Auth

Each browser tab maintains its own session. Sign in as different users in different tabs simultaneously.

06

🛡️ Admin Panel

Full dashboard with user management, content moderation, claim resolution, and account control.
